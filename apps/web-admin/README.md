# KeepEy Web Admin

This folder is reserved for the staff-facing Web Admin surface.

The Web Admin should follow:

- `docs/WEB_ADMIN.md` for page structure and behavior.
- `docs/design/DESIGN.md` for design routing.
- `docs/design/DESIGN_ADMIN.md` for admin-specific UI direction.
- `docs/DATA_MODEL.md` and `docs/API_CONTRACT.md` for shared data and integration contracts.

Local MVP data is stored in:

- `db/laptops.json`
- `db/rental_logs.json`

Do not mix Electron App UI files into this folder.
